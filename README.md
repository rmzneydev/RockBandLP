# 🎸  LINKIN PARK - Landing Page

## 📌 Project Description

This project is a responsive landing page for a rock band (LINKIN PARK). It demonstrates a clean HTML5 structure and CSS3 styling for a modern band promotion site.

The page includes a hero section, band information, tour/event details, and visual media content.

---

## 🛠️ Technologies Used

* HTML5
* CSS3

---

## 📁 Project Structure

```
├── index.html
├── README.md
├── style.css
├── script.js
└── img/
    └── [image assets]
```

`index.html` - main page for the landing page

`style.css` - stylesheet with layout, typography, and responsive rules

`script.js` - JavaScript file for interactive behaviors and enhancements

`img/` - folder with image assets used by the page

---

## 🚀 How to View the Project Locally

1. Clone or download the project repository.
2. Open `index.html` in your web browser.

> No installation is required.

---

## 🧱 Semantic HTML Tags Used

The page structure uses semantic HTML5 tags such as:

* `<header>`
* `<nav>`
* `<main>`
* `<section>`
* `<article>`
* `<footer>`

These tags help define the document structure clearly and improve accessibility.

---

## 🎨 CSS Techniques Applied

The stylesheet uses CSS3 techniques including:

* Flexbox for layout alignment and responsive section arrangement
* CSS Grid for structured content layout
* Media queries for mobile and desktop breakpoints
* Custom typography and spacing rules
* Background images, gradients, and hover effects for visual style

---

## 💡 Notes

* The page is built with semantic HTML5 tags.
* Responsive layout is handled with CSS3 and media queries.
* Use the `img/` folder to add or replace band visuals.
